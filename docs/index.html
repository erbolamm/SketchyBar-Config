Qué es

Un panel visual para editar tu configuración real de SketchyBar.

La app corre en tu Mac con Node.js + Express y trabaja sobre ~/.config/sketchybar/. No intenta reemplazar SketchyBar: lo hace más cómodo de configurar, probar y recargar.

Características

Lo esencial para ajustar la barra rápido

🎨

Apariencia visual

Cambiá posición, altura, blur y color con vista previa.

🧩

Plugins

Instalá, editá y guardá scripts para ampliar tu barra.

📝

Modificá sketchybarrc directamente cuando necesites control fino.

⚡

Guardar y recargar

Aplicá cambios desde un único flujo: guardar, recargar o iniciar si hace falta.

Instalación

Arrancá localmente

Primero instalá la barra oficial desde github.com/FelixKratz/SketchyBar. Después usá esta app para configurarla visualmente. 

brew install sketchybar

git clone https://github.com/erbolamm/SketchyBar-Config.git
cd SketchyBar-Config
npm install
npm start

Abrí http://localhost:2999 para usar la app.

Privacidad

Todo local, como corresponde.

ApliArte SketchyBar se ejecuta en tu equipo y edita archivos locales de SketchyBar. Los cambios afectan a tu configuración de macOS, así que revisá antes de guardar si tenés una configuración muy personalizada.
